# UI Test Case Kit

Небольшой учебный проект для практической работы № 5 по тестированию ПО.

Скрипт `testcase_checker.py` проверяет, что у тест-кейса указаны идентификатор, название, шаги и ожидаемый результат. Пример данных находится в `sample_cases.txt`.

Запуск: `python3 testcase_checker.py`

Структура ветвей: `main` — основной код, `documentation` — описание метода проверки, `graphics` — схема процесса.
